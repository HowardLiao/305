## ✨ 核心互動功能

- 🎲 **305 港都艷陽時光機（Sunny Gacha）**：隨機抽取一張經典照片，並附帶專屬高雄校園吉凶籤詩。
- 💖 **愛心點讚與我的珍藏（Favorites System）**：一鍵點讚收藏，資料保存於 LocalStorage，可點選「💖 我的珍藏」單獨檢視。
- 🔍 **即時關鍵字搜尋與智慧篩選**：支援輸入景點、同學名字、大合照等即時過濾。
- 📷 **復古拍立得模式（Polaroid Mode）**：一鍵切換成白色相紙外框、手寫體標註與微傾斜角度的拍立得照片牆。
- 🎵 **港都海風音樂電台（Pure Web Audio Synthesizer）**：採用純 Web Audio API 合成輕快明亮陽光海風旋律，零外部音訊檔案依賴。
- ▶️ **全螢幕自動幻燈片（Auto Slideshow）**：全螢幕高解析輪播，支援鍵盤左右箭頭切換與 Esc 退出。
- 📌 **青春塗鴉留言板（Interactive Guestbook Wall）**：訪客與同學可直接在網頁送出寄語，釘選於留言牆且重整不消失。

## 🛠️ 技術規格
- **架構**：單一輕量純靜態 HTML5 / CSS3 / Vanilla JavaScript（檔案大小約 180 KB）。
- **零本地容量負擔**：147 幀照片 100% 直連 Google 官方高頻寬雲端 CDN，不佔用伺服器與本機硬碟空間。
- **無外部函式庫依賴**：無 React / Vue / jQuery / Bootstrap 負擔，開箱即用，載入速度飛快。
